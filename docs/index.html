Core Architecture

Everything you love about Apple Music, powered by YouTube.

Engineered from the ground up on BitChord's native Android/Desktop InnerTube reverse-engineering pipeline.

BitChord Audio Engine

Direct 160kbps Opus stream resolution with real-time Stats for Nerds telemetry, buffer health metrics, and zero video decoding overhead.

1-Click Browser Sync

Foolproof 1-click session import with Private Network Access (PNA) support. Safely connects your Google account in seconds without login blocks.

Library & Playlist Sync

Multi-feed retrieval for your created playlists, liked songs, albums, and library shelves with responsive continuation pagination.

Real-time Synced Lyrics

Millisecond-precision time-synced lyrics via LRCLIB open API with frosted glass blur, smooth auto-scroll, and interactive click-to-seek.

Liquid Ambient Mesh

Hardware-accelerated 4-color dynamic gradient derived from album artwork color palettes, creating a responsive glowing aura across the window.

Web Audio Equalizer

5-band studio parametric equalizer with presets for Bass Boost, Acoustic, Vocal Booster, Treble Booster, and Flat audio profiles.

Discord RPC & Sleep Timer

Rich Discord RPC broadcasting track details, artist, elapsed duration, and album artwork, paired with an audio fade-out sleep timer.

Google TOS Compliance

Strict platform compliance: monetization ads are supported for free users, while YouTube Premium subscribers enjoy native ad-free playback.

Interactive Lyrics

Sing along with millisecond precision.

Deja queries LRCLIB using sanitized song metadata to provide time-synced lyrics with beautiful glowing active lines, gentle depth-of-field background blurs, and interactive click-to-seek.

  • ✓ Millisecond-accurate dynamic synchronization clock.
  • ✓ Click any lyric line to jump playback directly to that moment.
